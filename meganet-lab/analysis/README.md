# Análise

Este diretório reúne planilhas, notas e resultados consolidados da análise dos experimentos.

---

## Planilha de sessões

O arquivo [`planilha-modelo.csv`](planilha-modelo.csv) serve como modelo para registrar os resultados de cada sessão em formato tabular.

Abrir com LibreOffice Calc, Google Sheets ou qualquer editor de CSV.

---

## Como usar

Para cada sessão concluída:

1. Copiar uma linha de exemplo da planilha.
2. Preencher todos os campos com os valores da sessão.
3. Salvar e commitar apenas a planilha (não os arquivos brutos da sessão).
